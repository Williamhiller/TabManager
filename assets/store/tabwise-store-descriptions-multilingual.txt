English
=======

TabWise - Smart Tab Manager & Organizer

Bring tab chaos under control with a smarter Chrome workspace.

TabWise helps you auto-group tabs, remove duplicate tabs, clean inactive tabs, save snapshots, restore workspaces, search open tabs, track local tab activity, and manage bookmarks from one place.

Why install TabWise?

1. ⚡ AutoGroup tabs by rules
Automatically group tabs by website type, topic, domain, title, URL, website lists, or custom rules. Built-in presets include Shopping, Social, Media, Office, AI, Development, News, Finance, Travel, and Learning.

2. 🧹 Remove duplicate tabs
Automatically clean duplicate tabs with flexible modes: run globally, exclude selected sites, or only deduplicate listed sites.

3. 🌙 AutoClear inactive tabs
Collapse inactive groups, sleep inactive tabs, close inactive tabs, and protect important sites with cleanup whitelists.

4. 📸 Save and restore snapshots
Save the current window or all windows as snapshots, then restore your workspace later in a new window or the current window.

5. 🔍 Search everything fast
Find open tabs, history tabs, snapshots, and bookmarks quickly with search, smart views, and tab detail history.

6. 🔖 Manage bookmarks in the same workspace
Search bookmarks, create folders, save the active tab, edit bookmarks, move bookmarks, and delete bookmarks without leaving TabWise.

7. 🧭 Track local URL activity
Keep a local timeline of tab events such as created, closed, navigated, redirected, retitled, activated, pinned, muted, discarded, grouped, and ungrouped. Redirect tracking is optional and only runs after permission is granted.

8. 🖥️ Work from the popup, side panel, or dashboard
Use a quick popup, a focused side panel, or a full dashboard depending on how you manage tabs.

TabWise is built for people who open many tabs while researching, working, learning, shopping, comparing tools, or switching between projects. Install TabWise to auto-group tabs, remove duplicates, clean clutter, restore snapshots, and keep your browser workspace organized.

TabWise - 智能标签页管理与整理器

让混乱的 Chrome 标签页重新变得可控。

TabWise 可以帮助你自动分组标签页、移除重复标签、清理不活跃标签、保存快照、恢复工作区、搜索标签、记录本地标签活动，并在同一个工作区管理书签。

为什么安装 TabWise？

1. ⚡ 按规则自动分组标签页
可按网站类型、主题、域名、标题、URL、网站列表或自定义规则自动分组。内置预设包括购物、社交、媒体、办公、AI、开发、新闻、金融、出行和学习。

2. 🧹 移除重复标签
支持自动清理重复标签，可选择全局去重、排除指定网站，或只对指定网站去重。

3. 🌙 自动清理不活跃标签
支持自动折叠不活跃分组、休眠不活跃标签、关闭不活跃标签，并可用白名单保护重要网站。

4. 📸 保存和恢复快照
可将当前窗口或所有窗口保存为快照，稍后恢复到新窗口或当前窗口。

5. 🔍 快速搜索所有内容
可快速查找打开的标签、历史标签、快照和书签，并结合智能视图与标签详情历史定位内容。

6. 🔖 在同一工作区管理书签

7. 🧭 本地记录 URL 活动

8. 🖥️ 支持弹窗、侧边栏和 Dashboard
你可以使用快速弹窗、专注的侧边栏，或完整的 Dashboard 来管理标签页。

TabWise 适合经常打开大量标签页进行研究、工作、学习、购物、工具对比或多项目切换的用户。安装 TabWise，自动分组标签页、移除重复标签、清理杂乱内容、恢复快照，并保持浏览器工作区井然有序。

TabWise - スマートタブ管理・整理ツール

Chrome のタブ混乱を、すばやく整理されたワークスペースに変えます。

TabWise は、タブの自動グループ化、重複タブの削除、非アクティブタブの整理、スナップショットの保存と復元、タブ検索、ローカルのタブアクティビティ記録、ブックマーク管理を 1 つの場所で行えるツールです。

TabWise を使う理由

1. ⚡ ルールでタブを自動グループ化
サイト種別、トピック、ドメイン、タイトル、URL、サイトリスト、カスタムルールに基づいてタブを自動グループ化できます。Shopping、Social、Media、Office、AI、Development、News、Finance、Travel、Learning などのプリセットも用意されています。

2. 🧹 重複タブを削除
重複タブを自動で整理できます。全体に適用、特定サイトを除外、または指定サイトだけに適用するモードを選べます。

3. 🌙 非アクティブタブを AutoClear
非アクティブなグループの折りたたみ、非アクティブタブのスリープ、非アクティブタブのクローズに対応し、重要なサイトはホワイトリストで保護できます。

4. 📸 スナップショットを保存・復元
現在のウィンドウまたはすべてのウィンドウをスナップショットとして保存し、あとから新しいウィンドウまたは現在のウィンドウに復元できます。

5. 🔍 すばやく検索
開いているタブ、履歴タブ、スナップショット、ブックマークを検索し、スマートビューやタブ詳細履歴で目的の内容を見つけられます。

6. 🔖 同じワークスペースでブックマーク管理
ブックマーク検索、フォルダ作成、現在のタブの保存、ブックマーク編集、移動、削除ができます。

7. 🧭 URL アクティビティをローカルに記録
作成、クローズ、ナビゲーション、リダイレクト、タイトル変更、アクティブ化、固定、ミュート、破棄、グループ化、グループ解除などのタブイベントをローカルで記録します。リダイレクト追跡は任意で、許可された場合のみ有効になります。

8. 🖥️ ポップアップ、サイドパネル、Dashboard に対応
軽量なポップアップ、集中しやすいサイドパネル、またはフル機能の Dashboard から作業できます。

TabWise は、調査、仕事、学習、買い物、ツール比較、複数プロジェクトの切り替えで多くのタブを開く人に向いています。TabWise でタブを自動グループ化し、重複を削除し、不要なタブを整理し、スナップショットを復元して、ブラウザの作業環境を保ちましょう。
